# Lab 1 Workspace

This workspace is organized by file role:

- `src/`: C source files
- `bin/`: compiled programs
- `data/`: generated simulation output
- `scripts/`: helper scripts, including plotting

The VS Code build task compiles the active C file into `bin/`. Simulation programs write their output files into `data/`, and `scripts/plot.py` reads `data/projmotion`.
