# Cosmos Nanotech Quantum Mechanics

Quantum mechanics and computational physics lab work written in C and Python.

## Repository layout

- `labs-01-11/` contains the cumulative Lab 1 workspace for Labs 1–11,
  including simulation source code, helper scripts, datasets, and generated
  results.
- The repository root contains Lab 12 tight-binding, time-evolution, and
  annealing simulations, along with their plotting and animation scripts.

## Languages and tools

- C for numerical simulations
- Python for analysis, plotting, and animation
- NumPy and Matplotlib for scientific visualization

See [`labs-01-11/README.md`](labs-01-11/README.md) for the organization of the
earlier lab workspace.
