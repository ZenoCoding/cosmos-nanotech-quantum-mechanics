# Reconstructed Lab Index

The original `lab1` directory was cumulative and did not preserve assignment
numbers for most files. The Lab 0–11 split below is therefore an informed
reconstruction, not an authoritative syllabus.

The ordering uses four kinds of evidence:

1. increasing programming and numerical complexity;
2. source/data/script dependencies;
3. the original Git history, whose first commit contains the introductory C,
   series, random-number, and random-walk exercises;
4. the progression in related UC Davis computational-physics materials, which
   moves from C fundamentals through molecular dynamics, Kepler motion,
   diffusion, random walks, and matrices.
