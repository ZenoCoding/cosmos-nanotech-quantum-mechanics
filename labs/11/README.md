# Lab 11 — Lennard–Jones Molecular Dynamics

**Reconstruction confidence: medium.**

This is the most complex pre-quantum simulation: 200 particles interact in two
dimensions through a Lennard–Jones force, with trajectories saved to CSV and
animated in Python.

- `src/solid.c`
- `data/positions.csv`
- `scripts/animate_atoms.py`

Build with `make lab11`.
