# Labs 1–11 — Computational Physics Foundations

This cumulative workspace covers introductory C, numerical integration,
classical trajectories, diffusion, orbital dynamics, matrix operations, and
two-dimensional molecular dynamics.

## Layout

- `src/` — C source files
- `data/` — simulation output used by the visualizations
- `scripts/` — plotting and animation experiments
- `.vscode/` — the original editor build and launch configuration

From the repository root, run `make early` to compile all 26 runnable programs
into `build/01-11/`. Generated executables are intentionally not committed.
