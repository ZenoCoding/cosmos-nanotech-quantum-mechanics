# Lab 2 — Loops and Numerical Series

**Reconstruction confidence: high.**

These programs progress from finite sums to basic numerical approximation:

- `adder2.c` computes an integer series.
- `ex.c` approximates the exponential Taylor series.
- `newton1.c` applies Newton’s method to square roots.
- `quadratic1.c` solves a quadratic equation with discriminant checks.

Build with `make lab02`.
