# Lab 5 — Projectile Motion

**Reconstruction confidence: high.**

The projectile simulation extends time stepping to two dimensions and stops
when the particle returns to the ground. The Python scripts plot and animate
the resulting trajectory.

- `src/projectilemotion.c`
- `data/projmotion`
- `scripts/anim.py`
- `scripts/plot.py`

Build with `make lab05`.
